# Codex Token Overlay — русская версия

Плавающий счётчик токенов для Codex Desktop на Windows. Показывает расход токенов выбранного чата и заполнение контекста. При переключении чатов виджет ищет соответствующий локальный журнал.

Русскую версию поддерживает [aakonovalov](https://github.com/aakonovalov). Исходный проект [Codex Token Overlay](https://github.com/soleillevant0125/codex-token-overlay) разработали [soleillevant0125](https://github.com/soleillevant0125) и участники проекта. Программа распространяется по лицензии MIT и поддерживается сообществом.

## Установка на Windows x64

1. Скачайте автономный архив для Windows x64 из [раздела выпусков](https://github.com/aakonovalov/codex-token-overlay-ru/releases) и распакуйте его.
2. Запустите `CodexTokenOverlay.exe`.
3. Откройте Codex Desktop. Виджет появится поверх его окна. Нажмите на виджет для подробных показателей, нажмите правой кнопкой на значок в системном трее для настройки.

Для автозапуска при входе в Windows добавьте ярлык программы в папку автозагрузки, которую можно открыть командой `shell:startup`.

## Показатели

«Всего» показывает накопленное число входных и выходных токенов в журнале выбранного чата, включая кэшированные входные токены. «Ост.» показывает долю свободного контекста по данным последнего запроса. Оплата и лимиты подписки рассчитываются отдельно.

На Windows виджет определяет чат по заголовку окна и локальному индексу Codex. При совпадающих названиях чатов или недоступном заголовке появляется «Чат не определён». Изменения интерфейса Codex могут потребовать обновления виджета.

В меню трея можно выбрать показатели, закрепить текущий чат и настроить положение виджета. Уведомления о контексте срабатывают по умолчанию, когда остаётся 20%, 10% или 5%. Каждый порог срабатывает отдельно для каждого чата. Если свободный контекст снова превысит порог на 3 процентных пункта, уведомление можно получить повторно. При пересечении сразу нескольких порогов отображается самое срочное уведомление.

## Сборка на Windows

Требуется .NET 10 SDK. Выполните команду в PowerShell из корня проекта.

```powershell
dotnet publish src/CodexTokenOverlay/CodexTokenOverlay.csproj -c Release -r win-x64 --self-contained true -o dist/win-x64
```

Запустите `dist/win-x64/CodexTokenOverlay.exe`. Скрипт `Launch-ContextMonitor.cmd` запускает эту же сборку с отдельными настройками в `local-settings.json`. Для изменения порогов уведомлений закройте виджет и отредактируйте массив `ContextAlertThresholds` в этом файле, например `[25, 15, 5]`.

Для упаковки в ZIP запустите `./scripts/Publish-Local.ps1 -Variant Standalone`. Вариант `Lite` требует .NET 10 Desktop Runtime.

## Сборка на macOS

Требуется macOS 14 или новее и инструменты Xcode. Выполните команды из корня проекта.

```bash
swift test --package-path macos
bash macos/script/package_app.sh
```

Откройте `CodexTokenOverlay.app` из выходного каталога `artifacts/macos-*`. Виджет появится в строке меню. Он использует русский интерфейс при основном русском языке системы и английский при остальных языках.

Виджет macOS определяет открытый чат через локальный канал Codex. Если канал недоступен, счётчик показывает данные последней найденной сессии.
