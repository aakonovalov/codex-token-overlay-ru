# Codex Token Overlay — русская версия

Плавающий счётчик токенов для Codex Desktop на Windows. Показывает расход токенов выбранного чата и заполнение контекста. При переключении чатов виджет ищет соответствующий локальный журнал.

Это самостоятельная русская модификация [Codex Token Overlay](https://github.com/soleillevant0125/codex-token-overlay), созданного soleillevant0125 и участниками проекта. Исходная лицензия MIT и сведения об авторстве сохранены в файле LICENSE. Проект не связан с OpenAI.

## Установка на Windows x64

1. Скачайте архив из раздела Releases и распакуйте в удобную папку.
2. Запустите `CodexTokenOverlay.exe`.
3. Откройте Codex Desktop. Виджет появится поверх его окна. Нажмите на виджет для подробных показателей, нажмите правой кнопкой на значок в системном трее для настройки.

Для автозапуска при входе в Windows добавьте ярлык программы в папку автозагрузки, которую можно открыть командой `shell:startup`.

## Показатели

«Всего» — накопленное число входных и выходных токенов в журнале выбранного чата. Кэшированные входные токены входят в общий счётчик. «Осталось» — оценка свободного контекста последнего запроса. Данные журнала не являются счётом или показателем лимита подписки.

Виджет считывает локальные журналы Codex и определяет чат по заголовку окна и локальному индексу. При совпадающих названиях чатов или недоступном заголовке показывается «Чат не определён». Изменения интерфейса Codex могут потребовать обновления виджета.

## Сборка

Требуется .NET 10 SDK. В PowerShell из корня проекта выполните

```powershell
dotnet publish src/CodexTokenOverlay/CodexTokenOverlay.csproj -c Release -r win-x64 --self-contained true -o publish
```

Некоторые унаследованные тесты интерфейса ожидают исходные китайские подписи и размеры и нуждаются в обновлении для этой версии. Исходные файлы macOS сохранены из исходного проекта и не включают Windows-изменения русской версии.
