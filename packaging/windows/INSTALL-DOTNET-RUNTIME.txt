Codex Token Overlay Lite

Для версии Lite требуется Microsoft .NET 10 Desktop Runtime для архитектуры
вашей Windows. На странице Microsoft выберите установщик Desktop Runtime.

https://dotnet.microsoft.com/download/dotnet/10.0

Автономный архив для той же архитектуры поставляется без суффикса -lite
и включает среду выполнения .NET.
